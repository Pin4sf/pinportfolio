# Portfolio public-evidence inventory

**Date:** 2026-08-18  
**Scope:** Research-only inventory for a more personal founder + researcher + AI engineer portfolio. No portfolio code or public copy was changed.  
**Method:** Local-first review of the current portfolio, Waldo Brain, the current Waldo deck extraction, existing public artifacts, and the two portfolio handoff attachments. External links below were found in those sources; they were not live-reverified in this pass.

## Executive finding

The strongest portfolio is not a larger biography or a denser research page. It is a calm evidence system with four distinct layers:

1. **What I am building:** Waldo and Kennel.
2. **What I have learned by doing:** production agents, model/data infrastructure, harness research, memory, evaluation, and physical systems.
3. **What I believe:** machine execution should reduce what a person must carry; memory must remain correctable; authority should not silently expand; craft and reliability matter more than performative complexity.
4. **Who I am outside the thesis:** the Pokédex and jailbreaking origin, HackByte community-building, Japan and Kaizen, books, anime/films, and the habit of taking systems apart.

The current evidence supports the first three layers well. The fourth has several good anchors, but it needs a small founder-led curation pass rather than being inferred from private data.

## Recommended public content system

This is an inventory, not an implementation plan, but the evidence naturally supports six editorial modules:

1. **Now** — Waldo, one current question, one founder video.
2. **Work with evidence** — Atlan, Project EKA, Qwen3 MoE, Waldo/Kennel, HackByte, Smart Manufacturing.
3. **Research notebook** — outcome truth, governed memory, harnesses, and agents in the world.
4. **Field notes** — Japan, Industry 4.0, physical systems, design engineering, and observations from building.
5. **Things that shape how I build** — a small rotating shelf of books, anime/films, tools, and essays, each with a personal annotation.
6. **Sources and status** — distinguish built, observed, derived, historical, hypothesis, and direction without turning the homepage into a compliance document.

The governing editorial rule should be:

> **Show the event, the artifact, and the question it left behind. Let the worldview emerge from repetition.**
